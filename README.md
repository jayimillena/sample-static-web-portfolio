## 🚀 Local Quickstart Guide

Because this project is built as a single, static responsive HTML application, running it locally requires no build step or node installation.

### 1. Clone the repository
```bash
git clone https://github.com/your-username/jay-millena-portfolio.git
cd jay-millena-portfolio
```

### 2. View in Browser
Simply double-click `index.html` or open it directly inside your browser of choice:
```bash
# macOS
open index.html

# Linux
xdg-open index.html

# Windows
start index.html
```

Alternatively, serve it locally using PHP's built-in web server:
```bash
php -S localhost:8000
```
Then navigate to `http://localhost:8000`.
